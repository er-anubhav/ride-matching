# UrbanPulse Design System (Purple Edition)

This document outlines the visual tokens and design rules for the UrbanPulse Rider Application, based on the official purple brand identity and a premium minimalist layout similar to Uber.

## Theme Appearance
* **Theme Mode:** Dark Mode
* **Brand Accent Color:** `#6D0FA5` (Vibrant electric purple matching the official logo)
* **Background Color:** `#18181B` (Unified app background and surface)
* **Card/Surface Color:** `#18181B` (Sleek dark grey surface cards)
* **Status Colors:**
  * **Success/Online:** `#10B981` (Emerald)
  * **Warning/Alert:** `#F59E0B` (Amber)
  * **Error/SOS:** `#EF4444` (Crimson Red)

## Typography
* **Primary Font Family:** Plus Jakarta Sans
* **Heading 1 (Hero/Splash):** 32px Bold, Letter Spacing -1%
* **Heading 2 (Titles):** 20px SemiBold, Letter Spacing -0.5%
* **Subtitle/Body Large:** 16px Medium, Letter Spacing 0%
* **Body Regular:** 14px Regular, Color: `#A1A1AA`
* **Caption/Helper:** 12px Regular, Color: `#71717A`

## Component Shapes
* **Corner Roundness:** Fully Rounded (`ROUND_FULL` for buttons and badges)
* **Interactive Button Radius:** 28px (Pill shape)
* **Surface Card Radius:** 16px (Clean, sharp but slightly rounded similar to modern ride-sharing apps)
* **Input Fields Radius:** 12px
